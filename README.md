# 22-isotope-decay-plotter — 放射性同位体崩壊プロッター

## 概要
元素・半減期を選択すると指数関数的崩壊曲線をCanvas上にリアルタイム描画。残存率・崩壊時間の関係を教育用に可視化するSPA。

## 機能
- プリセット同位体選択（炭素-14 / ヨウ素-131 / ラジウム-226 / ウラン-238）
- カスタム半減期入力（単位: 秒/分/時間/日/年）
- Canvas上に指数関数崩壊曲線を描画（10半減期分）
- 経過時間スライダー → 現在残存率(%)とマーカーをリアルタイム表示
- 教育メモ（半減期1/5/10回時の残存率・崩壊式）表示

## 仕様
- 静的SPA、Tailwind CDN のみ、外部チャートライブラリ不使用（Canvas自前描画）
- escapeHtml() によるXSSガード実装済み
- aria-label / tabindex によるa11y対応

## ファイル
- `index.html` — 単一ファイルSPA
